# 카드사 결제 알림 설정

**이 설정을 안 하면 FamilyCard가 아무것도 못 합니다.**

앱은 카드사가 보내는 결제 알림을 읽어서 동작합니다. 알림이 안 오면 읽을 것도 없습니다.

---

## 두 가지를 확인하세요

### 1. 결제 알림이 켜져 있을 것

카드사 앱의 푸시 알림, 또는 문자(SMS) 알림 서비스.

### 2. 최소 금액이 **0원**일 것 ★

**이게 가장 자주 놓치는 부분입니다.**

많은 카드사가 "5만원 이상 결제만 알림"을 기본값으로 둡니다. 그대로 두면 커피값·편의점·교통비 같은 소액 결제가 **통째로 빠집니다.** 그런데 실적은 그런 소액이 쌓여서 채워집니다.

설정에서 알림 기준 금액을 찾아 **0원** 또는 **전체**로 바꿔주세요.

---

## 카드사별 설정 경로

> 카드사 앱은 업데이트로 메뉴 위치가 자주 바뀝니다. 아래 경로가 다르면 앱 안에서 **"알림"** 또는 **"이용알림"** 을 검색해보세요.

### 신한카드
```
신한SOL페이 앱 → 전체메뉴 → 설정 → 알림설정
  → 이용내역 알림  [켜기]
  → 알림 기준금액  [0원]
```

### KB국민카드
```
KB Pay 앱 → 전체메뉴 → 설정 → 알림 설정
  → 카드 이용알림  [켜기]
  → 알림 대상금액  [전체]
```

### 삼성카드
```
삼성카드 앱 → 전체메뉴 → 설정 → 알림 설정
  → 이용내역 알림  [켜기]
  → 기준금액  [0원]
```

### 현대카드
```
현대카드 앱 → 전체메뉴 → 설정 → 알림 설정
  → 카드 이용 알림  [켜기]
  → 최소 금액  [제한 없음]
```

### 롯데카드
```
롯데카드 앱 → 전체메뉴 → 설정 → 알림 관리
  → 승인내역 알림  [켜기]
  → 알림 기준금액  [0원]
```

### 하나카드
```
하나카드 앱 → 전체메뉴 → 설정 → 알림설정
  → 이용대금 알림  [켜기]
  → 기준금액  [전체]
```

### BC카드 / 비씨카드
```
페이북 앱 → 전체메뉴 → 설정 → 알림 설정
  → 카드 승인 알림  [켜기]
  → 금액 기준  [0원]
```

### NH농협카드
```
NH올원페이 앱 → 전체메뉴 → 설정 → 알림 설정
  → 카드 이용 알림  [켜기]
  → 알림 기준금액  [0원]
```

## 문자(SMS) 알림 서비스

카드사 앱 푸시 대신 **문자로 받는 서비스**도 있습니다. 앱은 양쪽 다 읽을 수 있습니다.

문자 알림 서비스는 카드사에 따라 **월 300원 안팎의 유료**인 경우가 있습니다. 앱 푸시가 잘 오면 굳이 신청할 필요는 없습니다.

다만 아래 경우엔 문자 쪽이 안정적입니다.

- 카드사 앱을 지웠거나 로그인을 안 하는 경우
- 카드사 앱 푸시가 자꾸 누락되는 경우

---

## 카카오 알림톡

일부 카드사는 카카오톡 알림톡으로 결제 알림을 보냅니다. 앱은 이것도 읽습니다.

별도 설정은 없고, 카카오톡 알림이 켜져 있으면 됩니다.

> **참고**: 앱은 카카오톡 알림 중 **발신자가 카드사인 것만** 읽습니다. 개인 대화는 저장조차 하지 않습니다.

---

## 설정을 마쳤으면

카드로 아무거나 결제해보세요. **커피 한 잔이면 충분합니다.**

1. 카드사 알림이 폰에 뜨는지 확인
2. 1~2분 뒤 FamilyCard 앱 대시보드에 그 결제가 나타나는지 확인

둘 다 되면 설정이 끝난 것입니다.

### 알림은 오는데 앱에 안 나타난다면

앱 **설정** 탭에서 권한 3개(알림 접근 / 문자 수신 / 배터리 최적화 예외)가 모두 초록불인지 확인하세요.

→ [사용자 가이드 - 문제가 생겼을 때](user-guide.md)

---

## 카드가 여러 장이면

**카드 한 장마다** 알림 설정이 따로 있는 카드사가 있습니다. 카드사 앱에서 카드별 알림 설정을 확인하세요.

한 장이라도 빠지면 그 카드는 실적이 0원으로 보입니다.

---

## 관리자에게 알려줄 것

설정을 마쳤으면 관리자에게 **카드 목록**을 알려주세요. 카드가 등록돼야 결제가 카드별로 정리됩니다.

카드마다 필요한 정보:

- 카드사
- **카드번호 뒤 4자리** (실물 카드를 보고 정확히)
- 카드 이름 (예: "신한 딥드림", "현대 the Green")
- 결제일

카드 이름은 **카드사 앱에 표시되는 이름과 비슷하게** 알려주면 좋습니다. 알림에 번호 없이 카드 이름만 오는 경우에 그걸로 구분합니다.
