# 카드 결제 알림 설정

FamilyCard는 카드사 API에 로그인하지 않고 폰에 도착한 결제 알림을 원문으로 수집합니다.
알림이 오지 않거나 금액 기준이 걸려 있으면 그 결제는 복구할 수 없습니다.

> 카드사 앱 메뉴는 자주 바뀌므로 이 문서는 고정 메뉴 경로를 단정하지 않습니다. 각 앱의
> 설정 검색에서 **이용알림**, **결제알림**, **푸시알림**을 찾아 현재 화면을 기준으로
> 확인하세요.

## 1. 결제 알림 켜기

본인이 실제로 쓰는 카드마다 카드사 앱의 승인·취소 이용알림을 켭니다. 같은 카드사라도
카드별 설정이 나뉘어 있을 수 있으므로 카드 한 장씩 확인합니다.

확인할 카드사 예:

- 신한, KB국민, 삼성, 현대, 롯데, 하나
- BC/페이북, NH농협, 우리
- 그 밖에 본인이 보유한 카드사

## 2. 알림 금액 기준을 전체로

최소 금액이 “5만원 이상”처럼 설정돼 있으면 소액 결제가 빠집니다. 가능한 경우 다음 중
하나로 맞춥니다.

- 0원 이상
- 모든 금액
- 제한 없음

설정을 바꾼 뒤 소액 결제도 폰 알림으로 실제 도착하는지 확인합니다.

## 3. 수신 채널 선택

### 카드사 앱 푸시

우선 권장합니다. 별도 SMS 이용료가 없고 알림 본문이 비교적 풍부한 경우가 많습니다.
FamilyCard **설정 → 수집 대상 → 카드사 앱 추가**를 누르고 검색창에서 공식 카드사 앱을
찾아 체크합니다. 신한·KB·삼성·현대·롯데·하나·NH·우리·BC 등 확인된 공식 앱은 먼저
표시되며 한 번에 여러 개를 선택할 수 있습니다. 패키지명을 직접 찾거나 USB로 연결할
필요가 없습니다.

### 결제·자산 앱

토스·카카오페이·네이버페이 같은 앱에서 카드 사용 알림을 받는다면
**결제·자산 앱 추가**에서 검색하고 여러 개를 한 번에 등록합니다. 토스·카카오페이·
네이버페이·PAYCO·삼성 월렛 등 확인된 앱은 먼저 표시됩니다. 같은 결제를 카드사 앱과
결제 앱이 둘 다 알릴 수도 있습니다. FamilyCard는 두 원문을 출처별로 보존하고, Phase 3의
거래 대사에서 한 결제로 묶습니다. 수집 단계에서 어느 한쪽을 끄거나 버리지 않습니다.

앱 하나를 등록하면 해당 앱이 보내는 모든 알림 본문이 수집 대상이 됩니다. 등록 확인창의
앱 이름과 패키지를 보고 공식 금융 앱이 맞는지 확인하세요. 카카오톡과 기본 문자 앱은
사생활 보호 때문에 이 방식으로 등록할 수 없습니다.

### SMS

카드사에 따라 유료 서비스일 수 있습니다. SMS를 쓸 때는:

- FamilyCard 앱의 문자 수신 권한 허용
- 결제 문자에 표시된 발신번호 또는 영문 발신자 ID를
  **설정 → 수집 대상 → SMS 발신자 추가**에 입력
- 발신번호와 거래 어휘가 모두 맞아야 수집됨

본문이 카드 알림처럼 보여도 확인되지 않은 발신번호는 개인정보 보호를 위해 거부합니다.

### 카카오 알림톡

카카오톡 패키지 전체를 허용하지 않습니다. **설정 → 수집 대상 → 카카오 공식 채널 추가**에서
알림에 표시되는 공식 채널 제목을 정확히 입력합니다. 카드사명으로 추정하지 않으므로 등록
전에는 알림톡이 수집되지 않는 것이 정상입니다.

Android가 알림 제목 외에 공식 채널 인증값을 제공하지 않으므로, 일반 대화방 이름을 공식
채널과 완전히 똑같이 만들면 구분할 수 없습니다. 해당 이름을 개인·단체 대화방에 쓰지 말고
아래 개인정보 canary를 반드시 확인하세요.

## 4. FamilyCard 수집 대상 관리

각 가족 구성원이 자기 폰에서 본인이 쓰는 것만 관리합니다.

1. **카드사 앱 추가** — 검색창에서 공식 카드사 앱을 찾아 필요한 앱을 모두 체크
2. **결제·자산 앱 추가** — 토스·카카오페이·네이버페이 등을 검색해 일괄 체크
3. 필요할 때만 **카카오 공식 채널 추가** 또는 **SMS 발신자 추가**
4. 더 이상 쓰지 않는 대상은 목록의 **삭제** 버튼으로 제거

삭제는 이후 새 알림 수집만 중단합니다. 이미 폰 큐나 집 서버에 보존된 원문은 복구·감사
근거이므로 삭제하지 않습니다. 같은 앱을 카드사/결제 앱의 다른 종류로 다시 추가하면 새
분류로 바뀝니다.

추천 목록은 자동 수집 목록이 아닙니다. 설치돼 있어도 사용자가 체크하고 등록을 확인해야만
새 알림이 수집됩니다. 목록에 없는 앱도 이름이나 패키지로 검색해 추가할 수 있습니다.

## 5. FamilyCard 권한

앱 설정 탭에서 다음을 확인합니다.

| 항목 | 필요 이유 |
|---|---|
| 알림 접근 | 허용된 카드 앱·알림톡을 받기 위해 |
| 문자 수신 | SMS 채널을 등록해 쓰는 경우에만 |
| 배터리 최적화 예외 | 백그라운드 누락을 줄이기 위해 |

알림 접근은 Android 특수 앱 접근 화면에서 직접 켜고, 문자 수신은 앱의 권한 요청 버튼으로
허용합니다.

## 6. 개발 단계 개인정보 canary

가족 전체 배포 전에 관리자가 반드시 다음을 시험합니다.

1. 일반 카카오 개인 대화
2. 카드사명이 들어간 일반 단체방 제목
3. “카드”, “승인”, “결제”가 들어간 개인 SMS
4. 등록한 카드사/결제 앱의 실제 승인 알림
5. 가능하면 같은 결제를 카드사 앱과 결제 앱이 동시에 알리는 경우

앞의 세 가지는 앱 pending/rejected 건수와 서버 `/raw`를 증가시키면 안 됩니다. 등록한
금융 알림만 서버에 도착해야 합니다. 5번은 `/raw`에 출처가 다른 원문 두 건으로 보여야
하며 아직 거래 중복을 판정하지 않습니다. 하나라도 사적 알림이 수집되면 즉시 배포를
중단합니다.

## 7. 정상 수집 확인

현재 Phase 2에서는 거래 대시보드가 아니라 관리자의 웹 `/raw` 화면이 기준입니다.

1. 실제 소액 결제
2. 카드사 알림이 폰에 뜨는지 확인
3. 앱의 `대기 중`이 네트워크 연결 후 0으로 돌아오는지 확인
4. 본인은 앱 대시보드의 **수집 원문 보기**, 관리자는 웹 `/raw`에서 해당 구성원 원문과
   **카드사 앱/결제 앱/카카오/SMS 출처 배지** 확인

원문에는 민감한 거래 정보가 있으므로 스크린샷이나 메신저로 전달하지 않습니다. 문제가 있으면
관리자에게 등록한 대상 이름과 앱의 **건수·상태 문구만** 알려줍니다.

## 8. 관리자에게 전달할 카드 정보

Phase 3 카드 매칭을 위해 다음만 안전한 채널로 전달합니다.

- 카드사
- 카드번호 뒤 4자리
- 카드 상품명
- 결제일

실제 결제 원문 전체는 전달하지 않습니다. 서버의 접근 제어된 `/raw`에서만 확인합니다.
