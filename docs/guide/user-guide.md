# 사용자 가이드 (가족용)

FamilyCard 앱을 처음 쓰는 분을 위한 안내입니다.

> **현재는 개발·실기기 검증 단계입니다.** 거래 정리·실적 화면은 Phase 3~4에서 완성됩니다.
> 지금 설치하는 테스트 사용자는 결제 원문이 안전하게 수집되는지만 확인합니다.

---

## 이 앱은 무엇인가요

카드로 결제하면 오는 **알림 문자를 자동으로 정리해주는 앱**입니다.

카드사 앱을 여러 개 열어보지 않아도 이번 달에 어느 카드로 얼마를 썼는지, 그리고 **실적을 얼마나 채웠는지** 한 화면에서 볼 수 있습니다.

### 개인정보는 어떻게 되나요

- 데이터는 **집에 있는 서버에만** 저장됩니다. 외부 회사 서버로 나가지 않습니다
- 앱은 **내가 설정에서 등록한** 카드 앱·결제 앱·알림톡 채널·SMS 발신자만 읽습니다.
  목록 밖의 카카오톡 대화나 다른 알림은 저장하지 않습니다
- 카드 비밀번호나 카드사 로그인 정보는 **입력하지 않습니다.** 앱은 그런 걸 묻지 않습니다
- **앱에서는 본인 카드만 보입니다.** 다른 가족의 사용내역은 보이지 않습니다

---

## 설치하기

### 1. 앱 받기

가족 관리자가 보내준 링크에서 APK 파일을 받아 설치합니다.

> "출처를 알 수 없는 앱" 경고가 뜨면 **설치 허용**을 눌러주세요. Play 스토어에 올리지 않은 가족용 앱이라 정상입니다.

### 2. 서버 연결

앱을 열고 **설정** 탭으로 갑니다.

1. 관리자가 알려준 **서버 주소**를 입력합니다
2. 관리자가 1회 보여준 **기기 토큰**을 직접 붙여넣습니다

QR 스캔은 아직 구현되지 않았습니다. 토큰을 놓쳤다면 관리자가 기존 기기를 폐기하고
새 토큰을 발급해야 합니다.

> 토큰은 **본인 것만** 써야 합니다. 다른 사람 토큰을 넣으면 그 사람 데이터로 잡힙니다.

### 3. 수집 대상 등록하기

설정의 **수집 대상**에서 본인이 실제로 쓰는 경로만 추가합니다. USB 연결이나 패키지명
조사는 필요하지 않습니다.

- **카드사 앱 추가**: 설치된 공식 카드사 앱 선택
- **결제·자산 앱 추가**: 토스·카카오페이·네이버페이 등 선택
- **카카오 공식 채널 추가**: 알림에 표시되는 공식 채널 제목 입력
- **SMS 발신자 추가**: 문자에 표시되는 번호 또는 발신자 ID 입력

더 이상 쓰지 않는 것은 목록에서 삭제할 수 있습니다. 삭제해도 과거 원문은 사라지지 않고
새 알림 수집만 멈춥니다. 같은 결제를 카드사 앱과 토스가 둘 다 알려도 정상이며, 원문은
출처별로 보존한 뒤 거래 정리 단계에서 한 건으로 묶습니다.

> 앱을 고르면 그 앱의 모든 알림 본문이 수집 대상이 됩니다. 반드시 공식 금융 앱인지
> 확인하세요. 카카오톡 개인 대화와 문자 전체가 수집되지 않도록 카카오톡·문자 앱 자체는
> 선택할 수 없습니다.

### 4. 필요한 권한 켜기

설정 탭에 권한 상태가 나옵니다. 알림 접근과 배터리 최적화 예외는 켜고, 문자 수신은
SMS 발신자를 등록해 쓸 때만 허용합니다.

| 권한 | 왜 필요한가 |
|---|---|
| **알림 접근** | 카드사 앱의 결제 알림을 읽기 위해 |
| **문자 수신** | SMS 발신자를 등록한 경우 문자 결제 알림을 읽기 위해 |
| **배터리 최적화 예외** | 안 켜면 폰이 앱을 잠재워서 알림을 놓칩니다 |

각 항목의 **[설정]** 버튼을 누르면 해당 시스템 화면으로 바로 갑니다.

### 5. 카드사 알림 켜기 ★ 가장 중요

**이 단계를 빼먹으면 앱이 아무것도 못 합니다.**

카드사 앱에서 결제 알림을 켜고, **최소 금액을 0원으로** 맞춰야 합니다. 기본값이 "5만원 이상만 알림"인 카드사가 있어서, 그대로 두면 소액 결제가 통째로 빠집니다.

→ **[카드사별 설정 방법](onboarding.md)** 을 보고 본인 카드사 설정을 마쳐주세요.

### 6. 확인

카드로 아무거나 결제해보세요. 커피 한 잔이면 충분합니다.

현재 Phase 2 검증에서는 관리자가 웹의 **`/raw` 원문 화면**에서 도착 여부를 확인합니다.
앱 거래 대시보드에는 Phase 3 파서가 완성되기 전까지 결제가 정리되어 나오지 않습니다.

## 화면 보는 법

### 대시보드

최종적으로 이번 달 카드별 사용금액이 카드 한 장씩 나옵니다. **현재 Phase 2에서는 빈 화면이
정상**이며, Phase 3부터 거래가 표시됩니다.

### 실적

이 화면은 Phase 4에서 제공될 예정입니다.

카드마다 진행률 막대가 나옵니다.

```
신한 딥드림 (1234)          [추정치]
████████████████░░░░░░  245,000 / 300,000
55,000원 더 쓰면 5% 할인 구간 달성
```

**"N원 더 쓰면 달성"** 이 이 앱의 핵심입니다. 이번 달에 어느 카드를 더 써야 할지 알려줍니다.

> **[추정치] 표시에 주의하세요.** 카드사가 계산하는 공식 수치와 다를 수 있습니다. 실적이 아슬아슬하면 카드사 앱에서 한 번 더 확인하세요.

`제외된 건 3건 ▸`을 누르면 실적에 안 들어간 결제와 그 이유를 볼 수 있습니다. 세금이나 상품권 구매는 대부분의 카드에서 실적으로 안 쳐줍니다.

## 가끔 확인할 것

### 카드 미확정 알림

```
⚠️ 카드 미확정 2건이 있습니다  [지정하러 가기]
```

알림에 카드 번호가 가려져 있어서 어느 카드인지 앱이 판단하지 못한 경우입니다. 눌러서 카드를 골라주면 됩니다.

**한 번만 골라주면 다음부터는 자동으로 인식합니다.** 처음 며칠은 몇 번 뜨지만 금방 없어집니다.

미확정 상태로 두면 **그 결제가 실적에 안 잡힙니다.** 보이면 바로 처리해주세요.

### 새 카드를 만들었다면

관리자에게 알려주세요. 카드를 등록해야 그 카드 결제가 정리됩니다.

## 문제가 생겼을 때

### 결제했는데 앱에 안 나와요

순서대로 확인해보세요.

1. **카드사 앱에서 결제 알림이 왔나요?**
   - 안 왔다면 → [카드사 알림 설정](onboarding.md)을 다시 확인하세요. 최소 금액이 0원인지 특히
2. **그 앱·카카오 채널·SMS 발신자가 수집 대상에 등록돼 있나요?**
   - 카드사 앱과 토스 등 실제 알림을 보내는 앱을 각각 등록해야 합니다
3. **필요한 권한이 켜져 있나요?**
   - 특히 **배터리 최적화 예외**가 자주 풀립니다
4. **"대기 중" 건수가 0이 아닌가요?**
   - 서버 연결이 안 돼서 대기 중일 수 있습니다. 아래 참고
5. **"확인 필요" 건수가 0이 아닌가요?**
   - 서버가 형식 오류로 거부한 원문을 앱이 삭제하지 않고 격리한 상태입니다. 관리자에게
     건수와 마지막 전송 문구만 알려주세요. 원문을 메신저로 보내지는 마세요

### "집 서버에 연결할 수 없습니다"가 떠요

```
📡 집 서버에 연결할 수 없습니다
   · Tailscale 이 켜져 있나요?
   · 집 서버가 켜져 있나요?
```

대부분 **Tailscale이 꺼져 있어서** 그렇습니다. Tailscale 앱을 열어 켜주세요.

**걱정하지 않으셔도 됩니다.** 화면이 안 보이는 것뿐이고, **결제 내역은 폰에 계속 저장되고 있습니다.** 연결이 되면 자동으로 올라갑니다.

### 며칠 동안 아무 결제도 안 올라와요

앱이 조용히 멈췄을 수 있습니다. 가장 흔한 원인은 **배터리 최적화**입니다.

설정 탭에서 권한 상태를 확인하고, 특히 배터리 최적화 예외가 꺼져 있으면 다시 켜주세요.

### 폰 기종별 추가 설정

일부 제조사는 자체 배터리 관리가 더 공격적이라 추가 설정이 필요합니다.

| 제조사 | 설정 경로 |
|---|---|
| **삼성** | 설정 > 배터리 > 백그라운드 사용 제한 > **절전 예외 앱**에 FamilyCard 추가 |
| **샤오미** | 설정 > 앱 관리 > FamilyCard > **자동 시작 허용**, 배터리 절약 → 제한 없음 |
| **LG** | 설정 > 배터리 > 절전 예외 앱에 추가 |

## 폰을 잃어버렸다면

**관리자에게 즉시 알려주세요.** 관리자가 해당 기기의 접근 권한을 폐기하면 그 폰에서는 더 이상 데이터를 볼 수 없습니다.

참고로 앱에서는 **본인 데이터만** 보이므로, 다른 가족의 사용내역이 함께 새지는 않습니다.

## 자주 묻는 질문

**Q. 카드 비밀번호를 넣어야 하나요?**
아니요. 이 앱은 카드사에 로그인하지 않습니다. 폰에 오는 알림만 읽습니다.

**Q. 다른 가족 사용내역도 볼 수 있나요?**
아니요. 앱에서는 본인 것만 보입니다. 가족 전체는 관리자만 웹에서 볼 수 있습니다.

**Q. 카드사 앱과 토스에서 같은 결제가 두 번 오면 사용금액도 두 배가 되나요?**
수집 원문은 증거 보존을 위해 둘 다 남기지만, 거래 처리 단계에서는 출처가 다른 같은 결제를
한 건으로 대사하도록 설계합니다. 현재 Phase 2에서는 `/raw`에 두 건이 보이는 것이 정상이며,
실제 문구를 모은 뒤 Phase 3에서 중복 집계 방지 규칙을 검증합니다.

**Q. 앱을 지우면 데이터가 사라지나요?**
서버에 올라간 데이터는 남습니다. 다만 앱 자동 백업은 보안상 꺼져 있어 **대기 중 원문과
확인 필요 원문은 앱 삭제·기기 교체 때 사라집니다.** 삭제 전에 대기 중이 0인지 확인하고,
확인 필요가 있으면 관리자와 먼저 처리하세요.

**Q. 실적 숫자가 카드사 앱과 다른데요?**
알림만 보고 계산한 추정치라 차이가 날 수 있습니다. 차이가 크면 관리자에게 알려주세요. 실적 규칙을 조정할 수 있습니다.

**Q. 해외에서 결제했는데 금액이 이상해요?**
해외 결제는 나중에 환율이 확정되면서 금액이 바뀝니다. 앱은 승인 시점 금액을 보여주므로 최종 청구액과 다를 수 있습니다.
