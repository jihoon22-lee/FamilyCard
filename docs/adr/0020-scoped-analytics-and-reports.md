# ADR 0020 — 가족 분석·예산·로컬 보고서

- 상태: 채택
- 날짜: 2026-09-25

## 결정

분석·구성원 드릴다운·보고서는 동일한 `analyticsScope`를 통해 `visibleMemberIds`를
통과한다. 클라이언트가 타인 memberId를 넘기면 거부한다. ADMIN 폰과 MEMBER 웹은 본인만,
관리자 웹은 가족을 본다. 예산은 개인/가족 × 전체/분류 조합을 지원하며 가족 예산 편집은
관리자 WEB/FAMILY만 가능하다. 카테고리 메타데이터는 공용이고 금액/거래는 scope 대상이다.

분석은 확정 승인 순사용액을 DB에서 집계한다. 13개월 추이는 작은 집계를 순서대로
조회하고 실적 계산도 카드별 순서대로 실행해 한꺼번에 장부를 메모리에 쌓지 않는다.
대시보드 실적 미리보기는 50장까지이며 초과는 명시하고 개별 화면으로 연결한다.
처리 실패 원문 건수와 거래 미확정은 구분하고 상태 보고 6시간 지연을 수집기 경고로 표시한다.

보고서는 서버 안에서만 생성한다. 엑셀은 10,000건, PDF는 2,000건 상한이며 잘린 파일을
전체 결과처럼 내보내지 않는다. 프로세스당 보고서 생성은 1개씩 허용하고 초과 동시 요청은
429로 돌려보낸다. 응답은 `private, no-store`이고 원문·토큰은 포함하지 않는다.
엑셀의 사용자 문자열은 수식이 아닌 문자 셀로 저장한다. PDF에는 OFL 한국어 폰트를
포함해 외부 서버나 클라이언트 폰트 설치 없이 읽을 수 있게 한다.

## 라이브러리 근거

- [ExcelJS 공식 문서](https://github.com/exceljs/exceljs): 문자열 셀과 XLSX writeBuffer.
- [PDFKit 공식 폰트/텍스트 문서](https://pdfkit.org/docs/text.html): OpenType 폰트 포함과 페이지 텍스트.
- [Noto CJK Sans 2.004 Korean subset](https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/SubsetOTF/KR/NotoSansKR-Regular.otf): OFL 1.1, 라이선스를 함께 보관.
- ExcelJS의 uuid 전이 의존성을 수정된 11.1.1로 고정하고 실제 XLSX 생성/재읽기를 검증.
  의존성 감사에서 알려진 취약점 0건을 확인했다.

## 검증

MEMBER 웹/ADMIN 폰/ADMIN 웹의 조회·예산·보고서 접근, 위조 구성원 ID, 순액/월 경계,
카테고리 비율과 예산 초과를 가공 DB로 검증한다. XLSX를 재읽어 수식 주입 방지와 정수
순액/KST 시각을 확인한다. PDF를 렌더링하고 한글 텍스트·마지막 행/페이지를 확인한다.
