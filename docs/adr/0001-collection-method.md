# ADR 0001 — 카드 사용내역 수집 방식

- **상태**: 채택
- **일자**: 2026-08-10

## 배경

가족 카드 사용내역을 자동으로 모으려면 카드 결제 데이터에 프로그램으로 접근해야 합니다. 한국에서 이게 가능한 경로를 조사했습니다.

## 검토한 대안

### 1. 마이데이터 표준 API (금융결제원)

금융 마이데이터 표준 API는 카드 승인내역·청구내역을 정식으로 제공합니다. 정확도가 가장 높고 법적으로도 명확합니다.

**탈락 이유**: 금융위원회 허가를 받은 **마이데이터 사업자만** 사용할 수 있습니다. 개인 개발자에게는 신청 경로 자체가 없습니다.

### 2. CODEF API (쿠콘)

카드사 웹/앱을 대신 스크래핑해 API로 제공하는 중개 서비스입니다. 개인 개발자도 가입할 수 있고, 필요한 API가 전부 있습니다.

- `개인 승인내역` — 결제 내역
- `개인 청구내역` — 청구 기준 확정 금액
- **`개인 실적조회`** — 카드사가 계산한 전월실적 그 자체

특히 **실적조회 API가 결정적**입니다. 전월실적은 카드사마다 제외항목이 달라 직접 계산하면 실제 수치와 어긋나는데, 이 API는 카드사가 계산한 값을 그대로 가져옵니다.

3개월 무료 데모(일 100회)와 샌드박스도 제공합니다.

**탈락 이유**: 데모 종료 후 **건당 과금**입니다. 가족 5명 × 카드 3장을 하루 몇 번씩 조회하면 호출량이 계속 발생합니다. 가족끼리 쓰는 개인 프로젝트에 지속적인 비용이 붙는 것이 부담스럽다는 판단이었습니다.

### 3. 안드로이드 알림·SMS 파싱 ← **채택**

카드사 앱과 토스·카카오페이·네이버페이 같은 결제/자산 앱의 푸시 알림, 카카오 알림톡,
SMS를 `NotificationListenerService`와 `BroadcastReceiver`로 캡처해 서버에서 파싱합니다.
수집 대상은 사용자 설정으로 관리하고 복수 출처 원문은 모두 보존합니다.

**장점**
- 비용 0
- 실시간 (결제 즉시)
- 외부 서비스 의존 없음. 카드사 인증정보를 어디에도 맡기지 않음

**단점**
- 승인 시점 정보만 있음. 할부 변경·해외 환율 확정액은 늦거나 누락
- 전월실적을 직접 계산해야 함 → 추정치
- 각 구성원이 알림 설정을 켜야 함 (최소 금액 임계값 0원)
- 카드사 문구 변경에 대응하는 유지보수 필요
- 안드로이드 전용 (iOS는 타 앱 알림 읽기가 OS 차원에서 불가)

### 4. 카드사 명세서 엑셀 수동 업로드

각자 카드사 홈페이지에서 이용내역 엑셀을 받아 올립니다.

**탈락 이유**: 매달 수동 작업이 필요해 주 수집 방식으로는 부적합. 다만 **정확도 보정 수단으로는 유용**해서 Phase 6에 넣었습니다.

## 결정

**안드로이드 알림·SMS 파싱을 주 수집 방식으로 채택합니다.**

가족 전원이 안드로이드를 쓰는 것이 확인되어 iOS 제약이 문제 되지 않습니다. 비용이 0이고, 카드사 인증정보를 외부에 맡기지 않는 점도 자가호스팅 방침과 맞습니다.

정확도 한계는 두 가지로 보완합니다.

1. **명세서 대사** (Phase 6) — 월 1회 카드사 엑셀로 대조해 누락을 메움
2. **추정치 명시** — 실적 수치를 카드사 공식 수치로 오인하지 않도록 UI에 항상 표기

## 재검토 조건

아래 상황이면 CODEF 도입을 다시 검토할 만합니다.

- 실적 추정치의 오차가 실사용에 지장을 줄 정도로 크게 나타날 때
- 카드사 문구 변경 대응 부담이 감당하기 어려워질 때
- 파싱으로 얻을 수 없는 정보(청구 확정액, 할부 잔액)가 필요해질 때

CODEF는 실적조회 API를 갖고 있어, 도입 시 실적 엔진을 "직접 계산" 대신 "조회값 사용"으로 대체할 수 있습니다. 데이터 모델은 그 전환을 막지 않도록 설계돼 있습니다 — `RawMessage.source`에 새 값을 추가하고 `Transaction`을 그대로 쓰면 됩니다.
