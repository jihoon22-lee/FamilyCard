# ADR 0022 — 운영·실적 알림과 선택 웹 푸시

- 상태: 채택
- 날짜: 2026-09-25

## 결정

운영 알림은 원문 수집과 별도의 1시간 주기로 실행한다. 기본값은 비활성이며 최종 배포에서
설정한다. 상태 보고 6시간 지연(결제 유무와 독립), 사이클 종료 5일 이내 최소 실적 구간
80% 미만, 이전에 관찰한 달성 구간 아래로 내려간 추정치를 알림으로 보존한다.
규칙 버전이 바뀐 경우는 취소로 단정하지 않으며 하락 알림에서 제외한다. 같은 사건 키로
반복 알림을 막는다. 한 번의 검사 사이에 달성/취소가 모두 발생한 변화는 관찰하지 못할 수 있다.

목록은 `visibleMemberIds`를 거치고 확인 처리는 본인 알림만 가능하다. 사용자 선택으로
브라우저 웹 푸시를 켤 수 있다. 관리자 WEB만 가족 알림 수신을 추가 선택할 수 있으며
DEVICE는 SELF를 유지한다. 기기 폐기와 관리자 권한 변경은 전달 시 다시 확인한다.

외부 브라우저 푸시 서비스에는 암호화된 **일반 안내만** 보낸다. 이름·카드·금액·거래 원문은
보내지 않는다. 알림을 누르면 로그인과 scope 확인을 거쳐 `/alerts`를 연다. 서비스 워커는
캐시/fetch 처리 없이 푸시와 클릭만 처리한다. WebView/브라우저 지원과 수신 권한은 별개다.

구독 주소는 지원하는 HTTPS 브라우저 공급자 도메인으로 제한하고 키 길이를 검증한다.
전송은 조건부 lease로 중복 작업을 줄이고 10초 제한, 1시간 간격 최대 5회 재시도한다.
404/410 구독은 비활성화한다. 한 사이클 50개 구독 상한이며 금융 내용은 로그에 남기지 않는다.
웹 푸시는 서비스 장애로 중복·지연될 수 있으며 동일 notification tag로 표시 중복을 줄인다.
알림 목록은 푸시 성공 여부와 무관하게 유지한다.

VAPID 키는 `scripts/generate-web-push-keys.mjs`로 한 번 생성한다. 키 파일은 private ignored
영역에만 보관하고 자동으로 운영 .env/외부 서비스에 적용하지 않는다. 실제 수신은 최종
설정·사용자 권한 허용 후 검증한다. 이 단계 테스트는 전송 함수를 mock해 외부 알림을 보내지 않는다.

## 근거

- [web-push 공식 API](https://github.com/web-push-libs/web-push): VAPID, 암호화, TTL/timeout/topic.
- [MDN PushManager.subscribe](https://developer.mozilla.org/en-US/docs/Web/API/PushManager/subscribe): 사용자 가시 알림과 applicationServerKey.

## 검증

가공 표본으로 임계·마감·규칙 변경·관찰된 구간 하락, DB 중복 방지·소유권·ADMIN 폰 가족
구독 거부, 일반 payload만 전송 mock, 구독 해제와 원문 비노출을 검증한다. 실기기 푸시 수신은 미완료다.
