# ADR 0008 — 검색·다중 선택이 가능한 최소 가시성 앱 선택기

- 상태: 승인
- 일자: 2026-08-30
- 대체: [ADR 0007](0007-user-managed-capture-sources.md)의 결정 2
- 관련: [Android 앱 설계](../design/08-android-app.md),
  [금융 앱 카탈로그 조사](../research/android-finance-app-catalog.md)

## 배경

ADR 0007은 설치 앱 목록을 직접 다루지 않기 위해 Android의 `ACTION_PICK_ACTIVITY` 시스템
선택기를 사용했습니다. 이 화면은 기기 구현에 따라 검색이 없고 한 번에 한 앱만 반환합니다.
앱이 많은 실제 폰에서는 사용자가 매번 긴 목록을 스크롤하고 선택기를 다시 열어야 하므로,
여러 카드사·결제 앱을 등록하는 정상 흐름이 지나치게 번거롭습니다. 카드사명과 현재 앱
표시명이 다른 경우(예: 삼성카드와 모니모)에는 찾기도 어렵습니다.

Android 11 이상에서는 다른 설치 앱 조회가 패키지 가시성의 적용을 받습니다. 편의를 위해
`QUERY_ALL_PACKAGES`를 요청하면 필요 이상의 설치 목록을 볼 수 있고 FamilyCard의 사생활
최소화 원칙과 맞지 않습니다.

## 결정

1. 매니페스트의 `<queries>`에 `MAIN` + `LAUNCHER` intent signature만 선언하고, 홈 화면에서
   실행 가능한 앱을 `queryIntentActivities`로 조회합니다. `QUERY_ALL_PACKAGES`는 선언하지
   않습니다.
2. 조회 결과에서 표시명과 패키지만 메모리에 두며 선택창이 닫힌 뒤 목록 전체를 저장하거나
   서버에 전송하지 않습니다. 사용자가 최종 등록한 출처만 기존 private 설정에 저장합니다.
3. 앱 안에 검색과 체크박스 다중 선택 화면을 제공합니다. 선택 결과는 한 번의
   SharedPreferences `commit`으로 원자적으로 반영합니다.
4. 국내 주요 카드·결제 앱의 공식 Play 패키지 목록은 추천 순서와 검색 별칭으로만 씁니다.
   자동 등록하거나 자동 수집 허용하지 않으며, 목록 밖 앱도 사용자가 검색해 고를 수 있습니다.
5. 공식 추천 다음에는 실제 표시명에 카드·Card·페이·Pay·월렛·Wallet이 들어간 앱을
   우선 표시합니다. 이름은 신뢰 경계가 아니라 탐색 편의 신호일 뿐입니다.
6. FamilyCard 자체·카카오톡·기본 SMS 앱은 조회 결과에서 제거하고, 기존 저장 정책에서도
   다시 거부합니다. 앱마다 모든 알림 본문이 대상이 된다는 최종 일괄 확인창을 유지합니다.

## 결과

- 사용자는 검색 한 번과 체크 여러 번으로 본인이 쓰는 앱을 등록할 수 있습니다.
- 공식 앱의 현재 표시명이 카드사명과 달라도 별칭 검색으로 찾을 수 있습니다.
- FamilyCard가 다루는 설치 목록은 실행 가능한 앱으로 한정되고 일시적으로만 존재합니다.
- 카탈로그가 낡거나 누락되어도 수집 경계가 넓어지지 않으며 일반 검색으로 우회할 수 있습니다.
- 매니페스트 변경이므로 이 기능을 받는 최초 한 번은 새 APK 덮어쓰기 설치가 필요합니다.

## 남는 위험과 완화

- 실행 가능한 앱 목록 자체도 사용자 설치 습관을 드러낼 수 있습니다. 서버 전송·디스크 저장·
  로그 출력을 금지하고 선택창이 열릴 때만 조회합니다.
- 동일 패키지에 런처 Activity가 여러 개면 중복될 수 있어 패키지 기준으로 하나만 표시합니다.
- 공식 앱 패키지는 바뀔 수 있습니다. 조사 문서에 출처와 확인일을 남기고 릴리스 전에
  재검토하되, 카탈로그 실패가 수집 허용으로 이어지지 않게 합니다.

## 기각한 대안

- **기존 시스템 선택기 유지**: 검색·다중 선택 요구를 충족하지 못합니다.
- **`QUERY_ALL_PACKAGES` 선언**: 실행 불가능한 패키지까지 볼 이유가 없고 과도한 권한입니다.
- **공식 목록을 자동 등록**: 사용하지 않는 앱이나 성격이 바뀐 앱의 알림까지 수집할 수 있어
  fail-closed 원칙을 어깁니다.
- **이름에 카드·Pay가 든 앱만 표시**: 이름이 다른 공식 앱과 새로운 앱을 찾지 못합니다.
