# ADR 0024 — 사용자 요청에 따른 실사용 검증용 0.3.0 배포

- 상태: 채택 (2026-09-26)
- 근거: 남은 실기기/실데이터 검증을 설명한 뒤 사용자가 “좋아 그럼 이제 최신화하고 버전 올리고 배포하자”라고 지시함.

## 결정

최신 사용자 지시에 따라 ADR 0014의 배포 대기 조건을 이번 검증용 업데이트에 한해 변경합니다.
구현/리뷰/격리 검증 완료 코드를 0.3.0으로 한 번 올리고 배포합니다. 실기기 재부팅,
개인정보 canary/RCS, 서명 백업 암호 별도 보관, 실제 카드/실적 한 사이클 검증은 미확인으로
유지하며 Phase 전체 완료나 1.0 정확도 보장을 선언하지 않습니다.

기존 설치와 같은 인증서로 로컬 release APK를 빌드합니다. 기존 개발 인증서 보존이지
새 운영 키 전환 완료가 아닙니다. 개인 키는 GitHub Secrets로 전송하지 않습니다.
로컬 APK/메타데이터를 draft Release에 올리고, 태그 CD는 저장소에 고정한 SHA-256과
인증서/패키지/버전을 확인한 뒤 같은 APK를 서버 이미지 및 Release에 포함합니다.

배포 전에 현재 DB dump/격리 복원·새 migration 리허설과 이전 이미지/APK를 확보합니다.
PR 필수 CI 성공/병합 뒤 태그를 발행하며, DB migration → 호환 서버 → 같은 서명 APK를
게시합니다. 원문과 기존 설정을 보존하고 앱 삭제·재설치나 DB reset은 하지 않습니다.
실제 표본 없는 파서/상품 조건은 등록하지 않으며 자동 처리·외부 푸시는 기본 꺼짐을 유지합니다.
