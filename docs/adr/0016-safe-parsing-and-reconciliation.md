# ADR 0016 — 규칙 실행·대사와 취소 재계산

- 상태: 채택, 격리 개발
- 날짜: 2026-09-25

## 안전한 파서

규칙 데이터는 [RE2JS](https://github.com/le0pard/re2js)의 비백트래킹 엔진으로 실행한다.
Node의 임의 RegExp/eval을 규칙 실행에 쓰지 않는다. 패턴 2,048자·반복 확장 합 1,024,
본문 64,000자/추출 설명 16,000자, 활성 규칙 256개, 컴파일 캐시 8개로 제한한다.
지원하지 않는 문법·변환·입력은 고정 실패 사유로 남기고 원문/정규식 예외를 로그에 쓰지 않는다.

RCS는 확인한 generalPurposeCard.content의 title/description과 legacy card 문자열만 읽는다.
버튼·링크·임의 JSON 필드를 모두 이어 붙이지 않는다. 원본은 변경하지 않는다.
정수 금액·외화 scale·실제 달력 날짜·KST 연도 복원·날짜 정밀도를 검증한다.
규칙 없음/규칙 오류/추출 실패/필드 오류/미지원 구조/무시 규칙을 구분한다.

실제 표본 없는 카드사 규칙은 자동 등록하지 않는다. 테스트의 일반 문구는 엔진 검증용
가공 형식이며 실제 지원 카드사 목록이 아니다. 사용자 첨부 KB 부분취소 형식은 이름·번호·
가맹점·금액·날짜를 바꾼 회귀 표본으로만 사용하고 운영 규칙으로 자동 활성화하지 않는다.

## 카드와 의미 중복

후보는 구성원·카드사·유효 기간으로 제한한다. 별칭/정확한 끝자리/정보가 있는 마스킹/
별칭 이름이 한 장에만 맞아야 확정한다. 식별자 없음이나 전부 마스킹은 단일 카드라도 미확정이다.

자동 병합에는 독립 출처, 일치하는 확정 카드/종류/금액/통화/가맹점/사건 시간 범위와
명시적인 **그 사건의 고유 식별번호**가 필요하다. approvalReference는 취소일 때도 취소 사건
고유 번호를 뜻한다. 원승인번호를 여기에 매핑해 여러 부분취소를 합치지 않는다.
금액/가맹점/시간만 닮은 복수 출처는 REVIEW이고 자동 집계에 중복 확정하지 않는다.
같은 출처의 별도 연속 결제를 내용 유사성만으로 합치지 않는다.

## 취소

확정 canonical 승인/취소에서 매번 취소 합계를 다시 계산한다. 이전 canceledAmount에
재가산하지 않는다. 같은 구성원/카드/통화·60일·잔여액·명시 원결제일 조건을 적용하고,
점수 60 이상 및 2위와 15점 이상 차이가 있어야 연결한다. 날짜만 있는 취소는 KST 당일 끝을
상한으로 써서 같은 날의 시간 있는 승인을 누락하지 않는다.
수동 연결은 먼저 잔여액을 확보한다. 잔여액 초과·동점·미확정 금액·원거래 없음은 이유를 남긴다.
늦은 승인 도착 후 재계산으로 고아 취소를 다시 평가한다. MERGED/REVIEW 취소는 중복 차감하지 않는다.
