# 즉시 실행 가능한 후속 작업

사용자 승인 순서: ① 미지원 원문/파서 보강 → ② 전체 처리 회귀 → ③ 미확정 대조 → ④ 자원 분석.

- [x] 1. 출처 제한/값 없는 형식 분석, 관측된 거래·비거래 규칙과 가공 회귀, 격리 재처리
- [x] 2. 새 형식 미확정→규칙 등록→과거/신규 처리→반복 재처리, 취소·수동 판단·scope·원문 검증
- [x] 3. 남은 중복 후보/취소 원거래를 기존 데이터에서 대조하고 해결 가능/근거 부족을 기록
- [x] 4. 저장된 감시 기록의 메모리·연결·지연 추이와 현재 적체 분석, 발견한 문제 개선/검증
- [ ] 최종 CI/병합, 백업 후 운영 적용, 원문/수동 판단 보존·화면 검증
- [ ] 문서/계획 갱신 및 작업 브랜치·임시 파일 정리

실물 카드/상품/환율을 추측하거나 사용자 수동 연결을 변경하지 않습니다. 원문과 실제 복원 DB,
백업은 영구 보존합니다. 미지원 형식/불명확한 거래를 숫자 맞추기용으로 무시하지 않습니다.
버전·APK는 유지하고 서버 수정으로 반영합니다. 외부 푸시/서명 전환/DB 외부 업로드는 범위 밖입니다.
